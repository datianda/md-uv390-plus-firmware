电台操作

发一个 E0 开头的 MMDVM 帧即可切换，不用按住 SK1 开机。 前提是先把 Options → General Options → Hotspot 从 Off 改成 MMDVM（配 Pi-Star / MMDVMHost）或 BlueDV。还是 Off 的话电台只会回一个 CPS 的 ACK。 切过去之后本控制端就连不上了，要退出得重启电台。

频段日志 需 ENABLE_BAND_LOG 固件

电台在 VFO 下扫描（长按 #）时，每扫完一轮写一条记录。 导出走 CPS 协议，每次 32 字节，128KB 约要一分钟，先导一小段看看。

AES 密钥 需 ENABLE_AES 固件

写入密钥本身不会开启加密发射 —— 发射密钥槽保持 0 时， 电台能解密收到的加密信号，但自己仍然发明文。 加密话音在多数国家的业余频段上不合法，仅限有牌照的商用/PMR 频段。

备份

做不到的事

OpenGD77 的串口协议里没有这些命令，所以本控制端也给不了：
· 遥控 PTT 发射
· 接收音频回传电脑
· 实时改运行中的频率（只能写 Flash 后重启）

协议的命令通道只有：屏幕接管、保存设置、重启、闪灯、初始化编解码器、设时间、GPS 日志。 能做收发控制的是热点模式（SK1+开机），那是另一套 MMDVM 协议，只走 DMR。
